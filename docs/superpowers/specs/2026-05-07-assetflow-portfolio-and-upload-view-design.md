# AssetFlow 资产总览、收益统计与上传图片查看设计

## 背景

AssetFlow 已经具备截图上传、OCR 识别、候选交易审核、交易流水、持仓快照和资金流水页面。当前界面仍有几个影响日常使用的缺口：

- 交易流水页面只能看逐笔记录，缺少对已卖出交易的合计收益统计。
- 总览页和上传页只能看到上传文件名，不能直接打开原始截图核对识别结果。
- 总览页最近交易只显示股票代码，不显示股票名称，快速辨认不方便。
- 总览页没有把持仓市值、现金余额和合计资产集中展示出来，难以查看整体资产情况。

本设计在现有 FastAPI + Jinja2 本地 UI 上做增量增强，不引入新的前端框架。

## 目标

- 在交易流水页展示按币种汇总的投资收益统计。
- 使用 FIFO 成本法计算已确认买卖交易的已实现盈亏。
- 将分红收入和交易费用纳入收益统计。
- 在总览页展示按币种汇总的持仓市值、现金余额和合计资产。
- 在总览页最近交易中展示股票名称。
- 在总览页和上传页提供原始上传图片查看入口。
- 保持现有数据库模型不变，第一版不新增收益落库表。

## 非目标

- 不做汇率换算，不把 HKD、USD、CNY 折算成单一基准币。
- 不做复杂收益率、年化收益、资金加权收益或归因分析。
- 不做历史资产曲线和图表。
- 不修改 OCR 识别逻辑。
- 不在第一版实现交易编辑后的收益缓存重算机制。

## 收益统计口径

第一版收益统计由三部分组成：

- FIFO 买卖已实现盈亏。
- 分红收入。
- 交易费用影响。

页面展示的总收益为：`FIFO 买卖已实现盈亏 + 分红收入 - 额外费用`。

统计范围：

- 只统计正式 `Transaction` 表中的已确认记录。
- 买卖盈亏包含 `trade_type="buy"` 和 `trade_type="sell"`。
- 分红收入包含 `trade_type="dividend"`。
- 额外费用包含 `trade_type="fee"`。
- 排除入金、出金和调整类型：`cash_in`、`cash_out`、`adjustment`。
- 按 `broker + account_alias + market + symbol + currency` 分组匹配成本。
- 按 `trade_date`、`trade_time`、`created_at`、`id` 排序。

买入处理：

- 买入形成一个库存批次。
- 批次数量为 `quantity`。
- 批次总成本优先使用现金变动口径：`abs(net_amount)`。
- 如果 `net_amount` 缺失，则使用 `gross_amount + commission + fees`。
- 如果仍缺失，则使用 `quantity * price + commission + fees`。
- 买入交易内的 `commission` 和 `fees` 是买入成本的一部分，不再作为额外费用重复扣减。

卖出处理：

- 卖出按最早买入批次依次扣减。
- 卖出收入优先使用 `net_amount`。
- 如果 `net_amount` 缺失，则使用 `gross_amount - commission - fees`。
- 单笔卖出如果被多个买入批次匹配，卖出收入按匹配数量比例分摊。
- 单笔卖出的已实现盈亏为：匹配卖出收入 - 匹配买入成本。
- 如果卖出数量超过已有买入库存，统计结果标记为存在未匹配数量。
- 卖出交易内的 `commission` 和 `fees` 已经通过净收入扣减，不再作为额外费用重复扣减。

分红处理：

- `trade_type="dividend"` 计入分红收入。
- 分红金额使用 `net_amount`；如果 `net_amount` 为负，则按原始符号计入，避免改写已确认流水含义。
- 如果分红记录有股票代码，则可归因到对应股票；如果代码为 `CASH` 或缺失，则只按币种计入未归因分红。

费用处理：

- `trade_type="fee"` 计入额外费用。
- 费用金额使用 `abs(net_amount)`。
- 只有独立费用流水计入额外费用；买卖交易字段里的 `commission` 和 `fees` 只用于买卖成本/收入计算，避免重复扣减。
- 如果券商把税费直接体现在买卖交易的 `net_amount` 中，收益统计按净现金变动计算，不额外估算一遍税费。

汇总展示：

- 按币种展示总收益。
- 同时展示 FIFO 买卖已实现盈亏、分红收入、额外费用、卖出收入、匹配成本、卖出数量、未匹配数量和交易笔数。
- 盈亏为正显示为收益，为负显示为亏损。
- 未匹配数量不强行估算成本，避免把缺失历史数据算成错误收益。

## 总览资产展示

总览页新增资产区，按币种展示：

- 持仓市值：来自最新 `PositionSnapshot.market_value` 汇总。
- 现金余额：来自最新 `CashSnapshot.cash_balance` 汇总。
- 合计资产：持仓市值 + 现金余额。

如果某个币种只有持仓或只有现金，也要显示该币种。缺失字段按 0 汇总，但表格中不展示为 `None`。

现有卡片可以调整为更直接的资产信息：

- 待审核数量。
- 最近交易数量。
- 持仓币种数量。
- 现金币种数量。

## 最近交易展示

总览页最近交易表增加股票名称列，展示：

- 交易日期。
- 股票代码。
- 股票名称。
- 交易类型。
- 数量。
- 现金变动。

股票名称使用 `Transaction.security_name`，为空时展示空字符串。

## 上传图片查看

新增本地 UI 图片查看端点：

- `GET /ui/uploads/{upload_id}/image`

行为：

- 根据 `upload_id` 读取 `Upload`。
- 找不到记录返回 404。
- 校验 `Upload.image_path` 解析后的真实路径必须位于 `settings.upload_dir` 内。
- 文件不存在返回 404。
- 使用 `FileResponse` 返回图片，`media_type` 使用数据库中的 `mime_type`。

安全边界：

- 不把 `image_path` 或 `content_hash` 暴露给 API 响应。
- 不接受任意路径参数。
- 不允许通过数据库外路径读取本机文件。

页面入口：

- 总览页最近上传表增加“查看”链接。
- 上传页最近上传表增加“查看”链接。
- 链接打开原始图片，便于核对 OCR 识别结果。

## 数据与模块边界

新增或调整的后端函数建议放在 `assetflow/dashboard.py`：

- `asset_totals(session)` 或整合进 `dashboard_summary(session)`。
- `transaction_profit_summary(session, filters...)`。
- FIFO 和收益汇总可以先作为 dashboard 层的纯函数，输入交易列表，输出统计结构。

UI 路由调整放在 `assetflow/ui.py`：

- 在 `/ui/transactions` 中传入收益统计结果。
- 在 `/ui/uploads/{upload_id}/image` 中实现安全图片返回。
- 总览页继续使用 `dashboard_summary(db)`。

模板调整：

- `dashboard.html` 展示资产汇总、最近交易名称、上传查看链接。
- `upload.html` 展示上传查看链接。
- `transactions.html` 在交易表上方展示收益统计。

第一版不修改数据库 schema。

## 错误处理

- 图片记录不存在：返回 404。
- 图片路径越界：返回 404，不暴露本地路径细节。
- 图片文件不存在：返回 404。
- 收益统计遇到未匹配卖出：页面展示未匹配数量提示，不中断页面渲染。
- 收益统计遇到无法计算成本的交易：跳过该部分成本并计入未匹配或不完整提示。
- 分红或费用缺少 `net_amount`：不计入金额，并在统计中计入不完整记录数。

## 测试策略

后端单元测试：

- FIFO 收益统计能按买入批次计算单币种已实现盈亏。
- FIFO 收益统计能处理部分卖出。
- FIFO 收益统计能标记没有足够买入库存的卖出。
- 收益统计能把分红计入总收益。
- 收益统计能把独立费用流水从总收益中扣减。
- 收益统计不会重复扣减买卖交易中已经进入净现金变动的佣金和费用。
- 总览汇总能同时包含持仓市值、现金余额和合计资产。

UI 测试：

- 交易流水页展示收益统计区。
- 总览页最近交易展示股票名称。
- 总览页和上传页为每条上传记录展示图片查看链接。
- 图片查看端点能返回上传图片内容。
- 图片查看端点拒绝越界路径。

回归测试：

- 交易流水明细表继续排除入金、出金和调整等非买卖流水。
- 收益统计区可以单独读取分红和费用流水。
- 上传列表 API 仍不暴露 `image_path` 和 `content_hash`。
- 现有完整测试套件保持通过。

## 验收标准

- 打开 `/ui/transactions` 能看到按币种汇总的总收益、买卖已实现盈亏、分红收入和额外费用。
- 存在卖出交易时，收益统计按 FIFO 匹配历史买入成本。
- 存在分红或费用流水时，收益统计会反映它们对总收益的影响。
- 打开 `/ui` 能看到每个币种的持仓市值、现金余额和合计资产。
- 总览最近交易能看到股票代码和股票名称。
- 总览页和上传页能点击查看原始上传截图。
- 图片查看端点不能读取上传目录以外的文件。
